🏛️ 1. End-to-End Pipeline Architecture

5-Phase Flow

Every query traverses 5 synchronous phases: Voice transcription via Sarvam AI, dense embedding with E5-Small, FAISS vector search, Cross-Encoder precision gating, and GPU-accelerated Qwen2.5-1.5B generation.

⚖️ 9. Reproduce the Benchmark

Judges' Guide

Judges can reproduce the complete automated benchmark scorecard with 1 command: 

# 1. Set environment variables
$env:OPENAI_API_KEY = "<YOUR_OPENAI_KEY>"
$env:EVAL_EMBEDDER_MODULE = "main"
$env:EVAL_GENERATOR_MODULE = "main"
$env:PYTHONPATH = "<path-to-rag-local-eval-loop>;<path-to-voice-rag>"

# 2. Run the official benchmark suite (100 queries)
.\venv\Scripts\python.exe -m eval.runner `
    --rag-root "." `
    --num-answerable 50 `
    --num-unanswerable 50 `
    --workers 1 `
    --judge-workers 16
